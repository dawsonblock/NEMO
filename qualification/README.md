# NeMo Relay qualification artifacts

This directory is generated by `scripts/qualification/run.sh`. Results use
`PASS`, `FAIL`, `INCONCLUSIVE`, `NOT_RUN`, and `NOT_APPLICABLE`; missing tools
never become an implied pass. Every run also records a source-tree manifest,
environment digest, lockfile digests, and Git provenance so the result is
bound to the files and tool versions that were actually exercised.

Run the full pinned matrix inside `.devcontainer`:

```bash
scripts/qualification/run.sh
```

Use `scripts/qualification/run.sh quick` only for a local diagnostic pass. A
quick run is not a release qualification certificate. An extracted tree can
still be identified by `source-tree.sha256`; set `NEMO_RELAY_SOURCE_ARCHIVE`
to include an archive digest when qualifying a packaged source tree. Use
`scripts/qualification/run.sh manifest` when only provenance capture is
possible; it intentionally reports checks as `NOT_RUN`.

Use `scripts/qualification/run.sh provenance` to refresh only the source and
environment digests without overwriting existing per-check logs. This is useful
after a source-only edit when the full matrix must be rerun in the pinned
environment before promotion.

The generated `source-manifest.json` excludes build products and generated
qualification output (`.git`, `target`, `node_modules`, `coverage`, and
`qualification`) and hashes every remaining source file. `qualification.json`
references that manifest through `provenance` and includes a reason for every
check state.
